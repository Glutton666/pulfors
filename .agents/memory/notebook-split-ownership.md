---
name: 오선노트 분할 음표의 원본
description: 마디 경계 분할과 사용자 입력을 분리하고, 손상된 예전 저장본을 보존하는 기준.
---

마디 경계에서 생긴 표시 조각과 붙임줄은 독립 입력이 아니다. 음표·쉼표를 옮기거나 복사하고, 다시 정리하거나 저장 후 열 때도 한 번 입력한 원래 표기와 음가를 사용한다.

**Why:** 표시 조각을 다음 재배치의 입력으로 다시 처리하면 같은 ID가 만들어지고 붙임줄이 자기 자신을 가리키며 총 음가가 줄어든다. 손상된 예전 저장본에서 원본은 추측할 수 없다.

**How to apply:** 첫 조각에 원래 입력의 ID를 유지하고, 페이지를 넘는 조각도 같은 입력의 일부로 다룬다. 저장본 비교에서는 생략된 선택 필드와 JSON 속성 순서를 편집으로 간주하지 않는다. 예전 조각은 온전한 연결이 확인될 때만 합쳐서 해석한다.
