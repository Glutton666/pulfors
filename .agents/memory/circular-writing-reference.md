---
name: 원형 서브디비전 그림 해석
description: 원형 입력의 사용자 그림과 강세 선택 메뉴를 해석할 때 지켜야 하는 의미
---

사용자가 확정한 두 번째 그림의 결과는 `A,N,A,N,A,N,A,N,S`의 9개 노트다. 마지막 S를 시작점으로 해석하거나 현재 노트의 S/A/N/M 선택 메뉴에서 다른 후보를 추가 노트로 세지 않는다. 처음 길게 누른 기존 비트는 그대로 유지하는 삽입 기준이며, 그 바로 뒤에 작성한 서브디비전이 적용된 새 비트 하나를 추가한다. 기존 마디의 비트 위치를 서브디비전 슬롯으로 사용하지 않는다.

**Why:** 사용자가 그림의 올바른 결과와 오독하지 말아야 할 점을 명시했다. 화면에 여러 강세 후보가 동시에 표시되는 것은 여러 노트가 작성된다는 뜻이 아니다.

**How to apply:** 원형 작성의 제스처·시각 표시를 변경하거나 사용자 그림을 다시 참조할 때 이 의미를 유지한다.

원형 작성은 설정에서 켜는 기능이 아니라 비트 모드의 기본 동작이다. 사용자가 말한 중앙 문제는 “원의 중앙이 인식이 잘안된다는 UI적 문제”이며, 터치 판정 변경 요구가 아니다.

**Why:** 사용자가 기존 비트를 덮어쓰는 동작을 정정했고, 설정 없이 기본 동작으로 제공하도록 요청했다. 중심 문제도 터치가 아니라 시각적 구별 문제라고 명시했다.

**How to apply:** 원형 작성의 활성화 방식이나 중심 표시를 수정할 때 이 범위를 유지하고, 기존 비트 및 후속 비트의 패턴과 음원을 보존한다.
