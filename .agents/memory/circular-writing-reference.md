---
name: 원형 서브디비전 그림 해석
description: 원형 입력의 사용자 그림과 강세 선택 메뉴를 해석할 때 지켜야 하는 의미
---

사용자가 확정한 두 번째 그림의 결과는 `A,N,A,N,A,N,A,N,S`의 9개 노트다. 마지막 S를 시작점으로 해석하거나 현재 노트의 S/A/N/M 선택 메뉴에서 다른 후보를 추가 노트로 세지 않는다. 그림의 원 둘레를 이동하더라도 처음 길게 누른 비트 하나가 작성 대상이며, 기존 마디의 비트 위치를 서브디비전 슬롯으로 사용하지 않는다.

**Why:** 사용자가 그림의 올바른 결과와 오독하지 말아야 할 점을 명시했다. 화면에 여러 강세 후보가 동시에 표시되는 것은 여러 노트가 작성된다는 뜻이 아니다.

**How to apply:** 원형 작성의 제스처·시각 표시를 변경하거나 사용자 그림을 다시 참조할 때 이 의미를 유지한다.
