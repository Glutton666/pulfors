---
name: 악보 입력 해석의 전제
description: 직접 연주 입력의 기보 해석 전제와 사용자가 선택한 입력·편집·표시 기준.
---

직접 쳐서 악보를 만드는 방식의 가능성을 평가할 때, 타격 직후 표기를 확정해야 한다는 전제를 두지 않는다. 사용자는 이후 문맥을 확인하면서 임시 표기를 갱신하는 방식을 논의하고 있다.

**Why:** 사용자가 “당장 악보를 듣자마자 써야” 할 필요는 없다고 정정했다. 초기 타격만으로 판단해야 한다는 제약을 임의로 추가하면 실제로 검토 중인 시스템과 다른 시스템을 평가하게 된다.

**How to apply:** 즉시 관측 가능한 입력과 이후 문맥으로 추정하는 기보를 구분한다. 이 논의는 구현 승인이나 모든 연주 의도를 자동으로 확정할 수 있다는 보장이 아니다.

우선하는 사용 상황은 “떠오른 리듬을 쳐서 빠르게 악보로 기록”이다. 사용자는 “악보를 따라 치며 정확도 연습”도 되면 좋겠다고 밝혔다.

**Why:** 사용자가 사용 상황의 우선순위를 직접 선택했다.

**How to apply:** 입력·수정 흐름은 리듬 기록을 우선해 검토하고, 따라 치기 연습을 추가 목표로 고려한다. 건반 멜로디·화음 입력이 불필요하다고 해석하지 않는다.

리듬 입력은 “BPM·박자를 설정하고 예비박을 들은 뒤 입력”하는 방식으로 검토한다.

**Why:** 사용자가 자유 연주 후 템포·박자를 추정하는 방식 대신 이 방식을 선택했다.

**How to apply:** 설정된 기준 박을 이용한 기보 해석을 전제로 삼는다. 자유 템포 분석을 확정된 요구사항으로 추가하지 않는다.

자동 기보는 “읽기 쉽게 정리하되 보정 정도를 조절 가능”한 방향이다.

**Why:** 사용자가 자동 정리 기준으로 조절 가능한 보정을 선택했다.

**How to apply:** 보정 정도를 조절하되 전체에 같은 보정을 적용한다. 구간별 별도 보정은 사용자가 선택하지 않았다.

## 사용자가 선택한 동작 기준

- 입력 화면은 큰 패드를 기본으로 드럼·건반으로 전환한다.
- 패드·드럼은 타격 중심, 건반은 누른 길이를 반영한다.
- 입력 종료는 마디 수 지정 또는 직접 정지 중 선택한다.
- 자동 재해석은 미확정 구간만 변경하고 직접 확정한 곳은 보호한다. 사용자는 “너무 길게 문맥을 읽으면 안되”라고 명시했고, 문맥 길이 상한으로 최대 한 마디를 선택했다.
- 드래그는 해당 음만 이동하고 주변 음길이·쉼표 변경안을 미리 보여준다.
- 단일 리듬의 쉼표·복잡한 연음부터 완성하는 것을 우선한다.
- 따라 치기에서는 타격 시점과 누락·추가 타격을 평가한다.
- 악보 색상에 대해 사용자는 “오선지는 무조건 휜색,검은샏으로”라고 명시했다.

**Why:** 사용자가 제시된 선택지와 추가 의견으로 직접 정한 요구사항이다.

**How to apply:** 향후 설계와 구현 범위에 이 기준을 반영한다. 최대 한 마디는 해석에 참고하는 문맥의 상한이지, 표시를 한 마디 끝까지 지연시키라는 요구가 아니다. 입력 화면의 세부 배치는 아직 확정된 것으로 취급하지 않는다.

## 도형 도구

사용자는 손으로 거칠게 그리는 입력이 아니라 “타원·선·곡선으로 기호를 구성하고 악보 요소로 지정”하는 도형 도구를 선택했다.

**Why:** 사용자가 “그려서가 아니라 그릴수 있는 도형툴이야. 거칠게 만들기 싫거든”이라고 정정한 뒤 도형 구성 방식을 선택했다.

**How to apply:** 완성 기호 배치만으로 요구를 대체하거나 단순 도형 주석으로 축소하지 않는다. 도형의 외형과 지정된 음악적 의미를 구분한다. 자동 인식이나 임의 기호의 재생 의미까지 확정된 요구로 추가하지 않는다.

## 추가로 확정한 편집·재생 기준

- 입력 종료 후 악보 초안을 확인한 뒤 확정한다.
- 음표 미세 조정은 박·연음 위치에 붙이기를 기본으로 하고 자유 이동으로 전환할 수 있다.
- 수정 후에도 기본 재생은 원래 입력이며, 수정된 악보는 비교 듣기로 제공한다.
- 해석 후보는 애매하거나 수정한 구간에서 제시하고 사용자가 직접 열 수도 있다.
- 도형으로 만든 기호의 음악적 역할과 속성은 사용자가 직접 지정한다.
- 직접 만든 기호는 개인 기호함에 저장해 재사용한다.
- 첫 연음 표현·편집 범위는 일반 연음과 음길이·쉼표가 섞인 연음, 사용자 지정 비율, 중첩 연음, 마디선을 넘는 연음을 모두 포함한다.

**Why:** 사용자가 남은 동작 선택지에서 각 항목을 직접 선택했고 연음 범위는 네 항목 모두 선택했다.

**How to apply:** 원래 입력을 기본 재생으로 선택한 것을 수정된 악보 기본 재생으로 바꾸지 않는다. 연음 표현·편집 지원을 모두 자동 인식한다는 보장으로 확대하지 않는다. 마디선을 넘는 연음 지원 때문에 자동 해석 문맥의 한 마디 상한을 임의로 늘리지 않는다.
