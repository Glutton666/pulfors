---
name: 리듬 악보 너비와 줄별 마디 수
description: 사용자가 정한 가로 스크롤 없는 기보와 줄 배치 기준
---

기보되는 악보는 좌우 스크롤 없이 화면 너비에 맞춘다. 사용자가 한 줄의 기본 마디 수를 정하며, 빽빽해도 마디 수를 자동으로 줄이지 않고 음표 크기도 줄여 맞춘다.

**Why:** 사용자가 화면에 맞는 악보와 선택한 마디 수 유지를 명시적으로 선택했다.

**How to apply:** 개별 줄도 사용자가 따로 조정할 수 있어야 한다. 특정 줄의 마디 수를 바꾸면 뒤쪽은 기본 마디 수로 다시 배치한다. 줄 선택을 통한 조정은 사용자가 제안한 UI 방향이며, 구체적인 선택 버튼 위치는 아직 확정하지 않았다.

음표 크기와 줄 간격을 직접 조정할 수 있어야 한다. 아주 짧은 타격 간격 하나를 기준으로 문서 전체를 축소해 사실상 보이지 않게 만들지 않는다.

**Why:** 사용자가 실제 화면에서 음표가 거의 안 보인다며 비율을 조정할 수 있게 해 달라고 요청했다. 너비 맞춤을 만족해도 음표가 읽히지 않으면 요구를 충족하지 않는다.

**How to apply:** 지정 마디 수와 가로 너비는 유지하되, 시간 간격의 최솟값을 전역 글리프 축소 기준으로 삼지 않는다. 배치 조정 뒤에도 크기·간격 설정을 유지하고 실제 화면에서 음표 크기를 확인한다.

사용자는 현재 음표 크기는 인식하기 좋으며, 문제는 “쉼표가 너무 중구난방으로 있어”라고 정정했다. 이 지적을 음표 크기 문제로 바꾸어 해석하지 않는다.

**Why:** 쉼표가 산만한 악보 사진에 대해 크기·배치 문제로 답하자 사용자가 문제의 초점을 다시 명시했다.

**How to apply:** 현재 음표 크기는 유지하고 쉼표 생성·분할과 리듬 해석을 먼저 확인한다. 쉼표를 숨기거나 음표를 늘리는 방식으로 입력 의미를 임의로 바꾸지 않는다.
