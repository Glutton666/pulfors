---
name: 리듬 악보 너비와 줄별 마디 수
description: 사용자가 정한 가로 스크롤 없는 기보와 줄 배치 기준
---

기보되는 악보는 좌우 스크롤 없이 화면 너비에 맞춘다. 사용자가 한 줄의 기본 마디 수를 정하며, 빽빽해도 마디 수를 자동으로 줄이지 않고 음표 크기도 줄여 맞춘다.

**Why:** 사용자가 화면에 맞는 악보와 선택한 마디 수 유지를 명시적으로 선택했다.

**How to apply:** 개별 줄도 사용자가 따로 조정할 수 있어야 한다. 특정 줄의 마디 수를 바꾸면 뒤쪽은 기본 마디 수로 다시 배치한다. 줄 선택을 통한 조정은 사용자가 제안한 UI 방향이며, 구체적인 선택 버튼 위치는 아직 확정하지 않았다.
