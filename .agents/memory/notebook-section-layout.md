---
name: 오선노트 구간과 표시 배율
description: 음자리표·박자표의 적용 범위와 표시 마디 수, 기준 클릭의 독립성.
---

새로 넣는 음자리표와 박자표는 놓은 줄의 첫 마디부터 같은 종류의 다음 변경점까지 각각 적용한다. 화면의 확대·축소로 줄이 바뀌어도 시작점은 원래 마디를 따른다. 기존 장식용 기호를 자동으로 변경점으로 간주하지 않는다.

**Why:** 사용자가 화면 배치를 바꾸더라도 악보 해석은 유지하고, 예전 문서를 열 때 기보의 의미가 바뀌지 않기를 원했다.

**How to apply:** 표시용 줄바꿈과 저장되는 마디 구조를 구분한다. 표시 마디 수는 배율로 조정하고, 설정에서 별도의 숫자나 1/4마디 옵션으로 중복해서 묻지 않는다. 기보 박자는 자동 배치와 화면 따라가기에서만 쓰고, 공통 템포를 제외한 상단 클릭·불러온 패턴의 박자와 리듬은 그대로 유지한다.
