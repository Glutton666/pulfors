---
name: GitHub workflow editing restriction
description: 이 프로젝트의 GitHub 워크플로 파일을 수정하지 않는 사용자 지침.
---

이 프로젝트에서는 앞으로 `.github/workflows` 파일을 수정하지 않는다.

**Why:** 사용자가 큰 커밋에 여러 변경이 섞인 일을 지적하며 해당 파일을 건드리지 말라고 요청했다. 이 제한 자체가 커밋 크기를 보장한다는 뜻은 아니다.

**How to apply:** 구현 및 작업 계획에서 해당 파일의 변경을 제외하고 기존 파일은 보존한다.
