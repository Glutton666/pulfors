---
name: 기능 화면의 창 중첩 지양
description: 독립 기능을 창 안의 창으로 구성하지 않으려는 사용자 방향.
---

사용자는 시그널 제너레이터를 포함해 “윈도우 안에 윈도우를 계속 넣는 방식이 너무 피로해”라고 했다. 이런 구성은 “설정같은 기능안에서 기능이어야” 한다고 했다.

**Why:** 독립 기능에서도 반복되는 창 중첩으로 사용자가 피로를 느낀다고 밝혔다.

**How to apply:** 독립 기능의 화면 구조를 설계할 때 반복되는 창 중첩을 지양한다. 실제로 겹치는 팝업, 교체되는 창, 단순한 화면 내 영역을 구분해서 설명한다. 조사 요청만으로 화면을 변경하지 않는다.

이번 창 구조 개선 범위는 시그널 제너레이터/튜너, 조율 가이드, 연습장, Work Up/연습 기록, 프로필, 음높이 퀴즈, 페이드아웃 연습이다. 어시스턴트, 드럼 키트, 예약 시작은 제외한다.

**Why:** 사용자가 개선 대상을 지정하고 예약 시작도 제외하겠다고 명시했다.

**How to apply:** 이 창 구조 개선에서는 제외한 세 기능을 변경하지 않는다.

화면으로 전환하더라도 기존 네이티브 Modal 전달 구조는 유지할 수 있다. 중요한 구분은 불투명한 독립 화면과 내부 화면 전환인지, 배경이 어두워지는 작은 창을 반복해서 겹치는지이다.

**Why:** 기존 뒤로 가기 처리, 단독 화면 진입, 튜너와 조율 가이드 사이의 상태 보존을 깨뜨리지 않으면서 사용자가 지적한 중첩 창 경험을 줄이기 위해서다.

**How to apply:** 후속 작업에서 컴포넌트 이름에 Modal이 있다는 이유만으로 라우팅 전체를 다시 만들지 않는다. 화면 전환 시 이전 작업 상태와 복귀 경로를 보존한다.

사용자가 말한 “창 안에 창”에는 화면 안의 큰 둥근 튜너 카드와 그 안의 별도 감지음 박스도 포함된다. 전체 화면으로 넓히기만 해서는 요구를 충족하지 않는다. 튜너 수치와 컨트롤을 화면에 직접 배치하고, 개별 버튼과 선택기의 조작 표시는 유지한다.

**Why:** 사용자가 전체 화면으로 바꾼 튜너 사진을 보고 “이것도 결국 창 안에 창 아니야”라고 다시 지적한 뒤 카드와 감지음 박스 제거를 승인했다.

**How to apply:** 모달 중첩 여부뿐 아니라 기능 전체를 감싸는 별도 배경·테두리·둥근 모서리도 확인한다. 다른 기능 전체를 임의로 바꾸지는 않는다.

독립 프로필 화면을 제공하더라도 프로필·백업/복원·앱 초기화 같은 공통 관리 항목은 통합 설정에서도 접근할 수 있게 유지한다.

**Why:** 사용자가 통합 설정에서 이런 항목이 사라졌다고 지적하고, 이 종류의 공통 관리 항목 복원을 요청했다.

**How to apply:** 화면 분리는 기존 공통 관리 진입점을 없애는 작업이 아니다. 독립 프로필과 통합 설정은 동일한 데이터·동작을 공유하고, 모드 전용 설정에는 공통 프로필 탭을 추가하지 않는다.
