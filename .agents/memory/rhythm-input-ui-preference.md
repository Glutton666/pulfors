---
name: 리듬 입력 화면 조작
description: 사용자 이미지와 길게 눌러 활성화·중지 및 탭 기록 표시 요구
---

입력 화면은 사용자가 제시한 그림처럼 악보를 위에 크게, 제어 줄과 큰 입력 패드를 아래에 둔다. 입력 시작은 길게 눌러 탭 버튼을 활성화하고 입력 중지는 악보 쪽을 길게 누르는 방식으로 한다. 탭 기록 상세 표시는 필요 없다.

**Why:** 사용자가 더 사용하기 좋은 입력 UI로 이 구성을 요청했다.

**How to apply:** 탭 기록을 안 보여주는 요구를 원본 입력 데이터 삭제로 해석하지 않는다. 길게 눌러 활성화한 시점과 실제 기록 시작 시점의 관계는 아직 사용자 확인 전이므로 별도로 확인한다.
