---
name: 웹·앱 공동 사용 범위
description: 웹을 별도 제품으로 다시 디자인하지 않고 앱과 같은 화면·기능 및 계정별 데이터 동기화를 제공한다.
---

사용자는 웹에서도 “그냥 앱이랑 똑같이” 쓰기를 원하며, 웹·앱 데이터 자동 동기화까지 선택했다.

**Why:** 웹 운영을 별도 안정화나 독립 제품 제작으로 구분하는 설명에 사용자가 이의를 제기했다. 현재 공통 Expo 화면을 유지하는 것이 요청에 맞는다.

**How to apply:** 기존 웹·앱 공통 화면과 기능을 보존하고, 같은 계정의 설정과 연습 데이터를 이어 쓰는 로그인·저장·동기화에 집중한다. 새 웹 앱이나 별도 디자인을 임의로 만들지 않는다.
