name: 웹·앱 공동 사용 범위
description: 기존 웹·앱 공통 화면을 유지한다. 현재 단계에서는 계정·자동 동기화를 보류하고 기존 수동 백업을 사용한다.
---

사용자는 웹에서도 “그냥 앱이랑 똑같이” 쓰기를 원한다. 자동 동기화도 처음 선택했지만, 이후 “계정 없이 기존 백업 기능만 일단 사용하게 해”로 현재 범위를 좁혔다. 도메인을 따로 구매·연결하지 않고 기존 Replit 주소를 그대로 사용하기로 했다.

**Why:** 웹 운영을 별도 안정화나 독립 제품 제작으로 구분하는 설명에 사용자가 이의를 제기했다. 현재 공통 Expo 화면을 유지하는 것이 요청에 맞는다.

**How to apply:** 기존 웹·앱 공통 화면과 기능을 보존하고 로그인 없이 로컬 저장과 기존 수동 백업을 유지한다. 계정·자동 동기화는 영구 폐지가 아니라 보류이며 새 요청이 있기 전에는 추가하지 않는다. 새 웹 앱이나 별도 디자인을 임의로 만들지 않는다.
