한국어 카운트는 공·일·둘·삼·넷·오·육·칠·팔·구를 사용한다. 10은 공, 12는 둘, 14는 넷, 16은 육처럼 끝자리만 읽는다. 이·사·영 또는 하나·둘·셋으로 자동 교정하지 않는다. 영어도 끝자리만 읽는다: 10→zero, 11→one, 12→two … 16→six. 이전의 영어 전체 숫자 규칙으로 되돌리지 않는다.

**Why:** 사용자가 지정한 리듬 읽기 발음이 일반적인 숫자 읽기 규칙과 다르며, 2026-10-13에 영어도 끝자리만 읽도록 변경을 확정했다.

**How to apply:** 새 음성 제작·교체나 카운트 UI 변경 때 이 발음 계약을 유지한다. 첫 분할은 기본 박 번호이고 뒤 분할은 해당 분할 순번이며, 공은 시작점 표시가 아니다. 음성 언어는 화면 언어와 독립적이다.

한국어 카운트는 영어식 발음이 아닌 자연스러운 한국어로 들려야 한다. 특히 넷이 네스, 오가 어처럼 들리지 않아야 한다.

**Why:** 사용자가 기존 한국어 카운트의 영어식 발음과 넷·오의 오청을 보고하고 수정을 요청했다.

**How to apply:** 한국어 음원을 제작·교체할 때 넷의 받침과 오의 모음을 실제 음원으로 비교 확인한다. 숫자 매핑이나 표시 문구 변경만으로 발음 문제가 해결됐다고 판단하지 않는다.

음성 카운트는 숫자를 길게 끌지 않고 짧고 또렷하게 읽는다.

**Why:** 사용자가 현재 숫자를 길게 끌면서 읽는 문제를 보고하며 음성이 더 짧기를 요청했다.

**How to apply:** 카운트 음원 제작·교체 때 불필요한 모음 늘임과 여운을 줄인다. 간결한 발화와 말끝 절단을 구분하고, 발음 식별성과 받침을 유지하며 실제 청취와 길이를 함께 비교한다.

남성·여성 선택은 서로 다른 카탈로그 화자의 오프라인 음원이어야 한다. 음성만은 기본·추가 메트로놈 클릭만 제거하고 독립 녹음 샘플은 유지한다. 음성 끔은 기존 클릭 출력을 복원한다.

**Why:** 사용자가 남녀 음성 선택과 클릭 없는 음성 카운트를 요청했으며, 기존 녹음과 카운트 출력은 독립 기능이다.

**How to apply:** 화자·출력 변경 시 숫자 규칙과 채널·강약·취소 소유권을 유지한다. 발화 길이 측정만으로 자연스러움이나 넷·오의 오청 해소를 확정하지 않는다.

Tempo는 외부 참고 앱이다. 참고 클릭과 닮은 음색은 독립적으로 합성하며, 그 앱의 샘플을 추출해 배포하거나 사용자의 목소리를 복제하지 않는다.

**Why:** 외부 음원을 재배포하지 않는 범위로 정한 요구다.

**How to apply:** 오프라인 번들 음성·클릭을 변경할 때 생성 출처를 유지한다. 매우 짧은 분할에서는 말소리가 겹쳐 명료도를 보장할 수 없으며, 이를 감추려고 번호를 생략하거나 템포를 바꾸지 않는다.
