---
name: 노트 큐 반복 범위
description: 연습장 소스의 반복 재생을 노트 모드에서 유지하는 규칙
---

비트와 반복 재생을 켠 바는 노트 큐에서도 사용자가 다음으로 넘길 때까지 현재 항목을 반복한다. 한 번 재생하도록 저장한 바만 자동으로 다음 항목으로 넘어간다. 반복 항목을 큐에서 눈에 띄게 표시한다.

**Why:** 사용자가 비트와 반복 바의 연습 시간을 직접 제어하기를 원했다. 노트 모드의 큐 전체 반복과 랜덤은 다음 항목의 순서를 정하며, 개별 항목을 넘기는 시점을 정하는 기능이 아니다.

**How to apply:** 예전 비트 저장본은 바 반복 필드가 `once`여도 연속 항목으로 해석한다. 반복 바의 내부 블록 순서, 횟수, 끝 부호는 한 바퀴 안에서 유지한다. 끝 부호가 노트 큐를 자동으로 진행시키지 않도록 끝 바의 전체 길이를 반복 기준으로 사용한다. 다음 버튼을 눌러 마친 반복은 이후 항목과 음원이 겹치지 않아야 한다.
