---
name: 시그널 튜너 UI 우선순위
description: 사용자가 원하는 튜너 중심 정보 위계와 간소화 방향.
---

시그널 제너레이터는 튜너로서의 기능을 강화하며, 감지와 타겟 주파수(동일하게 +/− 표시)가 주 기능이어야 한다. 간단하게 사용할 수 있는 UI로 간소화한다.

**Why:** 사용자가 시그널 제너레이터의 UI 변경 방향으로 요청했다.

**How to apply:** 화면을 정리할 때 발진기 상세 조작보다 감지와 타겟 주파수의 가독성·접근성을 우선한다. +/− 조절과 타겟 대비 부호 있는 편차는 서로 구분해 설명한다.
