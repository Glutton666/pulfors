---
name: 시그널 튜너 UI 우선순위
description: 사용자가 원하는 튜너 중심 정보 위계와 간소화 방향.
---

시그널 제너레이터는 튜너로서의 기능을 강화하며, 감지와 타겟 주파수(동일하게 +/− 표시)가 주 기능이어야 한다. 간단하게 사용할 수 있는 UI로 간소화한다.

**Why:** 사용자가 시그널 제너레이터의 UI 변경 방향으로 요청했다.

**How to apply:** 화면을 정리할 때 발진기 상세 조작보다 감지와 타겟 주파수의 가독성·접근성을 우선한다. +/− 조절과 타겟 대비 부호 있는 편차는 서로 구분해 설명한다.

타겟 오른쪽 음이름·옥타브는 위아래 슬라이드로 선택한다. 주파수 숫자는 짧게 누르면 입력하고 길게 누르는 동안 기준음을 재생한다. 마이크 버튼은 길게 누르고 뗄 때까지 분석용 소리를 수집하며, 결과를 아래에 표시한다. 별도의 발진기 설정·상세 분석 영역은 두지 않는다.

**Why:** 사용자가 메인 화면에서 직접 조작하는 이 흐름으로 바꾸라고 요청했다.

**How to apply:** 길게 누르기 후 짧은 누르기 동작이 중복 실행되지 않게 하고, 누름 종료·취소·화면 종료 시 출력과 수집을 정리한다.
