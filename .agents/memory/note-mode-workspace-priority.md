Note mode should use its vertical space as a coherent workspace, not leave widely separated controls and oversized empty sections. A whitespace complaint calls for reconsidering the layout, not just changing button appearance.

**Why:** The user said Note mode had too much blank space above and below and explicitly requested UI rearrangement after the settings-button styling change.

**How to apply:** Keep the upper mode dial available, give real queue/source content usable space, and keep import and playback actions easy to reach in empty and populated states. Do not restore equal-height empty queue/source regions merely to fill the viewport.
