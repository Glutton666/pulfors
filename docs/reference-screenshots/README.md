# Historical UI references

The 25 PNG screenshots formerly in the project root are preserved here without
re-encoding or deletion (678,124 bytes in total). Each moved file was compared
byte for byte with its previous saved version. No tracked text referenced their
old filenames at the time of the move.

These are historical references, not current acceptance-test evidence. Identical
pairs have deliberately been retained:

- `block-1-3.png` / `block-overlap-attempt.png`
- `beat_mode.png` / `final_beat_mode.png`
- `onboarding_colors.png` / `onboarding_colors_tiles.png`
- `theme_grid.png` / `theme_grid_tiles.png`

New automated screenshots belong in `/generated-artifacts/` or Playwright's
`test-results/`. Both are excluded from saved versions. This reference directory
remains saved, but is excluded from web deployment and native build uploads.
