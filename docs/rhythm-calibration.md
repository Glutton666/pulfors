# 리듬 입력 타이밍 보정

## 기준과 적용 범위

- 개인의 듣기·입력 오프셋을 추정한다. 순수 하드웨어 지연 측정이 아니다.
- 기존 메인 메트로놈의 PCM 렌더러로 클릭 간격을 트랙 안에 넣는다.
  네이티브는 준비된 WAV를 한 번 재생하며, 웹도 하나의 렌더 버퍼를
  미래 오디오 시각에 예약한다. 박마다 JS에서 소리를 시작하지 않는다.
- 녹음은 예비박과 본 녹음에 같은 트랙을 계속 재생한다. 보정 20박과
  따라 치기 예비박은 유한 길이 파일로 재생해 화면이 멈춰도 추가 클릭이
  나오지 않는다. 따라 치기의 실제 연주 재생기는 이번 변경 대상이 아니다.
- 웹은 출력 타임스탬프/출력 지연을 반영한 presentation clock을 사용한다.
  네이티브는 로딩과 재생 요청 후 양의 플레이어 위치가 처음 관찰될 때
  `관찰 시각 − 위치`를 소프트웨어 기준점으로 정한다. 입력과 같은 단조
  시계를 쓰되, 화면 콜백 도착 시각으로 박마다 기준을 다시 찍지 않는다.
- 네이티브의 위치 관찰에는 상태 갱신·브리지 지연이 남는다. 20ms 갱신
  요청은 정확도 보장이 아니다. 고정 보정값으로 실행별 시작 변동까지
  해결됐다고 간주하지 않는다.
- 이는 스피커/DAC의 물리 발음 시각이 아니다. 네이티브 드라이버·Bluetooth
  지연과 실제 손가락 입력은 별도 기기 확인이 필요하다.
- 예비 4박 후 16박을 측정한다. 기준음 준비 중·예비박 앞부분·완료 후
  탭은 결과를 바꾸지 않는다. 다시 시작·초기화·설정 닫기·화면 전환·앱
  비활성화는 이전 세션을 취소한다.
- 16개 박을 각각 대응시키고 누락·중복·한 박 밀림·불안정한 출력 간격과
  입력 편차를 거부한다. 실패한 보정은 기존 값을 유지한다.

## 부호와 데이터 보존

양수는 늦은 입력을 앞당긴다. 원본 down/up 값은 수정하지 않으며,
기보 시 적용하는 오프셋을 원본 재생에 소급하지 않는다.
원본 따라 치기의 기준과 실제 입력을 비교할 때는 두 쪽을 같은 보정
시간축으로 바꿔야 한다. 이미 보정된 기보 시각에 다시 빼지 않는다.
수동 범위는 −2000…2000ms이며 저장/재열기로 유지한다.
초기화는 화면의 숫자뿐 아니라 문서의 실제 적용값도 0으로 바꾼다.

## 검증과 한계

- 보정 패드는 지연된 버튼 활성화 대신 누르는 순간을 기록한다. 웹에서
  짧은 탭이 누락되는 회귀를 막기 위해 단일 버퍼의 예약 시각과 출력 시계를
  관찰하면서 각 박에 빠른 클릭을 보내 16박 완료와 보정값 적용을 확인한다. 청취나 물리 출력
  지연을 측정하는 검사는 아니다.
- 합성 입력 −80/0/+60ms 결과, 40ms 늦은 완전한 측정 패스,
  준비 지연, 초기화/재시작/해제 후 늦은 콜백, 기준음 없는 탭,
  누락·중복·한 박 밀린 탭과 큰 편차를 검사했다.
- 네이티브 모의 검사에서는 60ms/230ms 시작 지연을 따로 주고 양의 위치
  관찰 전에는 기준점을 만들지 않는지 확인한다. 실제 공유 렌더러의 PCM에서
  클릭 간격·루프 길이·정수가 아닌 BPM의 샘플 오차를 검사한다. 또한 한 번의
  재생, 정지/재시작 중 늦은 준비 취소, 파일 해제, 인터럽션·시작 타임아웃을
  검사한다. 실제 기기에서 소리를 청취했다는 뜻은 아니다.
- 컴포넌트에서 문서/표시값 초기화와 보정 1회 적용 후 연습 점수를
  확인했다. 브라우저에서 수동값 저장/재열기와 기준음 시작/초기화를 확인했다.
- Chromium의 마우스·터치 및 iframe 안의 터치 흐름과 단위 테스트를 사용했다.
  실제 iPhone/Android의 물리 출력
  시각, Safari 터치/오디오 정책, 보조기술은 이번 환경에서 확인하지 못했다.

## 기기 확인에서 분리해 기록할 값

세션의 `getTiming()`으로 요청·준비 완료·재생 요청·위치 관찰 시각,
관찰 위치·추정 원점·실제 PCM 박 간격과 시계 종류를 얻을 수 있다.
녹음 0점은 이 원점에 예비박 수 × PCM 박 간격을 더한 값이다.

반복 실행마다 이 값과 원본 down/up을 기록하고, 출력 녹음 장비가 있으면
실제 클릭 간격 및 시작 시각도 별도로 대조한다. 트랙 내부 클릭 간격 지터,
첫 출력 대비 녹음 0점의 실행별 변동, 고정적인 개인 입력 오프셋을
서로 다른 수치로 보고한다. 스피커·유선·Bluetooth, Android/iPhone 앱,
Samsung Browser 웹 결과를 합쳐서 한 플랫폼이 검증됐다고 하지 않는다.
